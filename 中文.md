# 3D 音乐碟片盒子展示网站项目总结文档

## 1. 项目概述

### 项目名称

3D Album Box Interactive Music Collection

### 核心概念

将传统音乐专辑（Album Cover / CD Box）重新设计为具有空间感的 3D 收藏盒。

用户通过浏览一组排列在空间中的专辑盒子：

-   初始状态：多个专辑盒从右侧进入视野，以侧面书脊形式排列。
-   滚动浏览：用户滚动页面，整个专辑墙横向移动，可以查看更多收藏。
-   Hover：鼠标悬浮时产生类似 tilted-card 的轻微倾斜反馈。
-   点击专辑：
    -   当前盒子从队列中脱离。
    -   移动至视觉中心。
    -   旋转展示正面封面。
    -   其他专辑保持侧面排列状态。
-   再次点击当前专辑：
    -   盒子打开。
    -   光盘（CD / Vinyl）推出。
    -   光盘开始旋转。
    -   音乐播放器启动。
-   点击其他专辑：
    -   当前专辑关闭。
    -   光盘收回。
    -   盒子回到侧边排列。
    -   新选择的专辑执行展开流程。

# 3. 核心交互状态设计

## State 01：Initial Loading

### 状态

专辑盒子从右侧进入。

动画：

    translateX(120vw)
            ↓
    translateX(0)
            ↓
    排列完成

效果：

-   stagger delay
-   opacity fade in
-   slight rotation

实现：

GSAP Timeline

``` js
albumList.forEach((album,index)=>{
 timeline.from(album,{
   x:window.innerWidth,
   rotateY:-90,
   delay:index*0.08
 })
})
```

# 13. 最终效果目标

一个类似：

-   高级音乐收藏馆
-   数字唱片店
-   3D Apple Music 展示空间

的沉浸式 Web Experience。

核心体验：

    Browse Collection

    ↓

    Select Album

    ↓

    Reveal Artwork

    ↓

    Play Music

    ↓

    Return Collection

项目重点不是播放器，而是：

「让用户像拿起真实唱片一样，与音乐收藏产生空间互动。」
